# 🌟 Muhannadek Budget Tracker 🌟

Welcome to the **Muhannadek Budget Tracker**, a user-friendly application designed to manage personal finances efficiently. The tracker allows users to add, view, and delete income and expense entries while providing a clear summary of their total budget.

---

## 🚀 **Features**

- 📋 **Entry Management**: Add, edit, and delete income or expense entries with ease.
- 🌙 **Dark Mode Toggle**: (Optional Feature) Enhance user experience with light/dark mode.
- 📊 **Real-Time Summary**: Automatically calculates and updates the total budget based on user entries.
- 🖥 **Responsive Design**: Optimized for both desktop and mobile use.
- 💾 **Local Storage Integration**: Data is saved locally, ensuring your entries are available even after refreshing the page.

---

## 🛠 **Technologies Used**

- **Frontend**: Vanilla JavaScript (ES6+)
- **Styling**: CSS, Bootstrap
- **Hosting**: GitHub Pages
- **Data Management**: Local Storage API
- **Validation**: Custom input validation for accurate data entry
